# To_Do_List
QUANTOMICS ACADEMY REGISTRATION FORM


📝 Basic To-Do List Web App

A simple and responsive To-Do List application built using HTML, CSS, and JavaScript.
This project allows users to add, complete, and delete tasks easily. It is designed as a beginner-friendly project to practice basic web development concepts.

🚀 Features

➕ Add new tasks

✅ Mark tasks as completed

❌ Delete tasks

📱 Simple and responsive UI

⚡ Fast and lightweight (no frameworks)

🛠️ Technologies Used

HTML5 – Structure of the application

CSS3 – Styling and layout

JavaScript (Vanilla JS) – Task functionality and DOM manipulation

📂 Project Structure
todo-list/
│
├── index.html      # Main HTML file
├── style.css       # Styling for the app
├── script.js       # JavaScript logic
└── README.md       # Project documentation
